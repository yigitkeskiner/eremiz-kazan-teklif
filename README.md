# Erem Group Vercel Site

Bu repo statik bir web sitesi olarak hazırlandı. Vercel'e doğrudan proje olarak bağlanabilir.

## Dosyalar

- `index.html`: Sayfa içeriği (kazan teklif aracı)
- `styles.css`: Profesyonel kurumsal arayüz tasarımı
- `script.js`: Kazan teklif hesaplama mantığı
- `kazan_alti.js`: Kazan altı sistemi (denge kabı, ayırıcı, vana vb.) hesap mantığı
- `vercel.json`: Vercel için basit yönlendirme ayarı
- `pompa-hidrofor/`: Marka bağımsız pompa &amp; hidrofor ön seçim aracı (`/pompa-hidrofor`)
  - `index.html`, `pompa.css`: sayfa ve stil
  - `data.js`: ürün veritabanı, Alarko Optima eğri verisi ve açılır menü listeleri
    (ERM Pompa Seçim Teklif Sistemi V1 Excel dosyasından üretildi — **ürün/fiyat verileri örnektir**,
    gerçek liste ile değiştirilmeden müşteriye teklif verilmemelidir)
  - `script.js`: Q/H hesap modülleri (hidrofor, sirkülasyon, kazan dairesi), Alarko Optima
    değişken/sabit basınç eğri kontrolü ve 100 puanlık ürün eşleştirme motoru
